# freeCodeCamp Daily Coding Challenge - April 27

## Word Score

Given a word, return its score using a standard letter-value table:

|Letter|Value|
|:----:|:---:|
|  A   |  1  |
|  B   |  2  |
| ...  | ... |
|  Z   | 26  |

* Upper and lowercase letters have the same value.

### Tests:

1. `getWordScore("hi")` should return `17`.
2. `getWordScore("hello")` should return `52`.
3. `getWordScore("hippopotamus")` should return `169`.
4. `getWordScore("freeCodeCamp")` should return `94`.
