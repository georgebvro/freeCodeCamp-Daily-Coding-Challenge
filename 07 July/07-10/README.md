# freeCodeCamp Daily Coding Challenge - July 10

## Exact Change

Given an integer amount in cents, return the number of distinct ways to make exact change using pennies (1 cent), nickels (5 cents), dimes (10 cents), and quarters (25 cents).

### Tests:

1. `exactChange(3)` should return `1`.
2. `exactChange(9)` should return `2`.
3. `exactChange(17)` should return `6`.
4. `exactChange(39)` should return `24`.
5. `exactChange(61)` should return `73`.
6. `exactChange(99)` should return `213`.
